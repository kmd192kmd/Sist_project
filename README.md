# 🏫 교육센터 운영 관리 시스템 (Oracle Database Project)

쌍용 교육 센터의 과정을 관리하고 교육생의 성적, 출결 및 사후 처리를 통합 관리하는 데이터베이스 기반 시스템입니다.

---

## 📌 1. 프로젝트 개요
- **개발 환경**: Oracle Database 21c, Java (JDK 11 이상)
- **목적**: 교육 과정의 설계부터 모집, 운영(성적/출결), 장비 할당, 취업 지원까지의 전체 프로세스를 데이터베이스 기반으로 설계하고 관리함
- **사용자 권한**: 관리자(Admin), 교사(Teacher), 교육생(Student)

## 💡 3. ERD 수정 및 고도화 사례
프로젝트 설계 과정에서 발견된 기존 모델의 한계점과 이를 해결하기 위한 수정 사항입니다.

### 🔍 문제 발견 (Discovery)
- **자산 관리의 부재**: 기존 설계에서는 '강의실' 단위의 관리는 가능했으나, 교육생 개개인에게 할당되는 **PC 및 사물함**에 대한 이력 관리가 불가능했습니다.
- **운영 효율성 저하**: 특정 자산(PC 등)의 고장 상태나 수리 현황을 별도로 기록할 곳이 없어, 행정 업무 시 수기 관리가 병행되는 비효율을 확인했습니다.

### 🛠 해결 및 수정 (Resolution)
1.  **자산 관리 엔티티 세분화**: `COMPUTER`, `LOCKER` 테이블을 독립시키고, 교육생과의 할당 관계를 관리하는 `PERSONAL_COMPUTER`, `PERSONAL_LOCKER` 매핑 테이블을 추가했습니다.
2.  **상태 관리 시스템 도입**: `COMPUTER_STATUS` 테이블을 통해 장비의 현재 상태(정상, 수리 중, 폐기 등)를 코드화하여 실시간 모니터링이 가능하도록 설계했습니다.
3.  **이력 관리 강화**: 할당 날짜(`allocationDate`)와 종료 날짜(`endDate`) 컬럼을 배치하여, 교육생의 수료 후 자산 회수 여부를 명확히 파악할 수 있도록 고도화했습니다.

## 🔑 4. 주요 기능 요구사항

### 🛡 관리자 (Admin)
- **기초 정보 및 계정 관리**: 과정, 과목, 강의실, 교사 및 교육생 정보 CRUD
- **개설 관리**: 과정 및 과목 개설, 강의실 및 교사 배정
- **시설 관리**: 강의실 내 컴퓨터 및 사물함 현황 관리 및 교육생 할당
- **성적/출결 모니터링**: 전체 교육생의 성적 조회 및 기간별 출결 현황 분석

### 👨‍🏫 교사 (Teacher)
- **강의 스케줄**: 담당 과정의 강의 예정/중/종료 상태 확인
- **성적 관리**: 과목별 배점(출결, 필기, 실기) 등록 및 교육생 성적 입력
- **출결 관리**: 담당 교육생의 근태 조회 및 관리

### 👨‍🎓 교육생 (Student)
- **정보 및 성적 조회**: 본인의 수강 정보, 교재, 강사 정보 및 과목별 취득 점수 확인
- **출결 및 시설**: 일일 출퇴근 기록 및 본인에게 할당된 PC/사물함 정보 확인

## 🛠 5. 기술적 구현 세부사항

### 1️⃣ Tables & DDL
- 데이터 의존성을 고려한 **5단계 계층 구조** 설계
- 참조 무결성(FK)을 보장하는 정교한 제약 조건 설정

### 2️⃣ Java 기반 정교한 더미 데이터 생성
현실적인 데이터 환경을 위해 Java 프로그램을 작성하여 대량의 DML을 생성했습니다.
- **Attendance.java**: 2024년~2027년 공휴일 및 주말 제외 로직 적용. 난수 알고리즘을 통한 현실적 근태 확률(정상 85%, 지각 10%, 결석 5%) 반영.
- **Instructor.java**: 성/이름 배열 조합을 통한 20명의 고유 교사 데이터 생성. 중복 없는 주민등록번호 및 전화번호 생성 알고리즘 적용.
- **Student.java**: 교육생 시퀀스와 수강 상태("수강대기")를 연동한 대량 Insert 쿼리 생성.

### 3️⃣ PL/SQL 및 비즈니스 로직
- **프로시저**: 교육생 성적 일괄 산출 및 수료 처리 자동화
- **트리거**: 출결 기록 시 실시간 근태 상태(지각, 조퇴 등) 자동 판별

## 🗃 6. 데이터베이스 명명 규칙 (Naming Rule)
- **Table**: 대문자 및 언더스코어(`_`) 사용 (예: `REGISTERED_COURSE`)
- **Column**: 카멜 케이스(`camelCase`) 사용 (예: `registeredCourseSeq`)
